# Smart IoT Plate Reading System

An IoT-based vehicle monitoring system developed as a Final Year Project at German-Malaysian Institute (GMI).

## About the Project

The Smart IoT Plate Reading System (APRS) is designed to automate vehicle identification and monitoring using license plate recognition technology.

The system helps improve vehicle access management by detecting vehicle registration plates and recording vehicle entry and exit activities.

## Features

- Automatic vehicle license plate recognition
- Vehicle entry and exit monitoring
- Student mobile application
- Admin dashboard
- Vehicle record management
- Traffic monitoring and reporting

## Technologies Used

- Flutter
- Dart
- IoT Hardware
- License Plate Recognition
- Database Management
