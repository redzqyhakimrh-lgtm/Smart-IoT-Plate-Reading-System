# Smart IoT Plate Reading System

## About the Project

Smart IoT Plate Reading System is a Final Year Project developed to automate vehicle identification and monitoring through license plate recognition technology.

The system is designed to improve vehicle access management by detecting vehicle registration plates and recording vehicle entry and exit activities.

## Main Features

- Automatic vehicle license plate recognition.
- Vehicle entry and exit monitoring.
- Student mobile application.
- Admin dashboard for vehicle monitoring.
- Vehicle record management.
- Traffic monitoring and reporting.

## Technologies Used

- Flutter / Dart
- IoT Hardware
- License Plate Recognition
- Database Management

## Project Type

Final Year Project – German-Malaysian Institute (GMI)
